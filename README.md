About the Project

The Student Result Management System is a Python-based application designed to manage student information and academic results.

Features

* Student registration
* Student identification using unique student IDs
* Recording and updating student scores
* Calculation of total scores and averages
* Automatic grade calculation
* Date and time tracking for entered results
* Saving student records using JSON files
* Generating student result reports

Technologies Used

* Python
* JSON
* Visual Studio Code (VS Code)
